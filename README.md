## Overview

This repository contains an **ecommerce microservices** system built with **Spring Boot + Spring Cloud**.

The project is organized as multiple services registered with **Eureka**, configured via **Spring Cloud Config**, and secured using **Spring Security + JWT**.

## Tech Stack

- Java + Spring Boot
- Spring Cloud Config (Config Client)
- Netflix Eureka (Service Discovery)
- Spring Security
- JWT (JJWT)
- Spring Data JPA
- MySQL
- Validation (Jakarta Validation)
- Lombok
- Spring Boot Actuator
